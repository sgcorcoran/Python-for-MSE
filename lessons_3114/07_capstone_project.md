# MSE 3114: AI-Augmented Materials Science - Capstone Project

**Course:** MSE 3114 - AI-Augmented Materials Science

**Prerequisites:** MSE 2114, completion of Lessons 1-6

## Project Overview

The capstone project is your opportunity to demonstrate mastery of AI-augmented materials science techniques by conducting a comprehensive analysis of real materials data. You will integrate all the skills learned throughout the course: AI tool usage, prompt engineering, modern data processing, statistical analysis, experimental design, and machine learning.

## Learning Objectives

By completing this capstone project, you will:

1. **Integrate AI Tools**: Demonstrate proficiency in using ChatGPT, Claude, and GitHub Copilot for materials science analysis
2. **Apply Modern Data Science**: Use Polars, Streamlit, and Plotly for efficient data processing and visualization
3. **Conduct Statistical Analysis**: Perform comprehensive statistical analysis with AI assistance for interpretation
4. **Design Experiments**: Create and analyze experimental designs using AI-guided optimization
5. **Implement Machine Learning**: Build and evaluate ML models for materials property prediction
6. **Communicate Results**: Present findings in a professional, AI-enhanced report format

## Project Structure

### Phase 1: Project Planning and Data Collection (Week 13, Days 1-3)

#### 1.1 Project Selection
Choose ONE of the following project types:

**Option A: Alloy Property Optimization**
- Analyze a dataset of alloy compositions and mechanical properties
- Use AI to identify optimal composition ranges for specific applications
- Implement ML models to predict properties from composition

**Option B: Microstructural Analysis**
- Work with image data of material microstructures
- Use AI to analyze grain size, phase distribution, or defect detection
- Implement statistical analysis of microstructural features

**Option C: Process Parameter Optimization**
- Analyze experimental data from materials processing
- Use DOE principles to optimize process parameters
- Implement ML models for process optimization

#### 1.3 Data Collection and Preparation
- **Data Source**: Use provided datasets, your own research data, or publicly available materials science datasets
- **Data Quality**: Apply the data quality checks learned in Lesson 1
- **Data Cleaning**: Use Polars for efficient data processing
- **Documentation**: Document your data source, structure, and any preprocessing steps

### Phase 2: Analysis and Modeling (Week 13, Days 4-7)

#### 2.1 Exploratory Data Analysis
- **Statistical Summary**: Generate comprehensive descriptive statistics
- **Data Visualization**: Create informative plots using Plotly and Streamlit
- **AI-Assisted Insights**: Use AI tools to identify patterns and anomalies in your data

#### 2.2 Statistical Analysis
- **Assumption Checking**: Verify normality, homogeneity, and independence assumptions
- **Hypothesis Testing**: Conduct appropriate statistical tests based on your data characteristics
- **AI Interpretation**: Use AI to help interpret statistical results and their practical significance

#### 2.3 Machine Learning Implementation
- **Model Selection**: Choose appropriate ML algorithms based on your problem type
- **Feature Engineering**: Use AI assistance to identify relevant features and transformations
- **Model Training**: Implement cross-validation and hyperparameter tuning
- **Performance Evaluation**: Assess model performance using appropriate metrics

### Phase 3: Results and Presentation (Week 14, Days 1-5)

#### 3.1 Results Compilation
- **Statistical Results**: Compile all statistical analysis results
- **ML Model Performance**: Document model accuracy, precision, recall, and other relevant metrics
- **Visualizations**: Create final, publication-ready figures and charts

#### 3.3 Final Presentation Preparation
- **Executive Summary**: Create a 1-page summary of key findings
