# Survey Analysis Guide for MSE 3114 Mid-Course Evaluation

## How to Use This Survey

### Distribution Options:
1. **Google Forms** (Recommended): Copy questions into a Google Form for easy collection and analysis
2. **Canvas Survey**: Create survey in Canvas for integrated access
3. **Paper Survey**: Print and collect anonymously
4. **Microsoft Forms**: Similar to Google Forms

### Key Questions to Analyze:

#### **Critical for Lesson Tweaks:**

**Question 10 (Concerns)**: Identifies what students fear most
- High concern about "AI Validation" → Add more scaffolding to Lesson 05
- High concern about "Integrated workflows" → Simplify Lesson 06
- High concern about "Capstone" → Provide more structure in Lesson 07

**Question 11 (Support Needs)**: Directly tells you what to add
- "More Python basics review" → Add Python review sections to upcoming lessons
- "Step-by-step AI validation examples" → Enhance Lesson 05 examples
- "More worked examples" → Add complete workflow walkthroughs

**Question 6 (Challenges)**: Identifies gaps to address
- High "Python basics" → Consider Python review options
- High "Finding files/folders" → Add file navigation guidance

**Question 3 (Pacing)**: Tells you if lessons are too fast/slow
- Majority "too fast" → Reduce content or add more time
- Majority "too slow" → Can add more depth or challenge

## Analysis Framework

### For Each Lesson (05-07):

#### **Lesson 05: AI Validation & Critical Evaluation**
**Look for:**
- Question 9: Concerns about detecting AI errors (high → needs more scaffolding)
- Question 11: Need for "step-by-step AI validation examples" (high → add worked examples)
- Question 6: "Hard to know when AI is correct vs. incorrect" (high → this is the lesson's focus!)

**Actionable Adjustments:**
- If >50% concerned about AI Validation → Add more gradual difficulty progression
- If >50% need "step-by-step examples" → Create detailed walkthrough examples
- If >40% struggle with "trusting AI code" → Emphasize validation checkpoints

#### **Lesson 06: Integrated Workflows**
**Look for:**
- Question 6: "Following complex workflows" challenge (high → simplify workflow structure)
- Question 11: Need for "worked examples of complete workflows" (high → add comprehensive examples)
- Question 10: Concern about "Integrated workflows" (high → break into smaller steps)

**Actionable Adjustments:**
- If >40% struggle with workflows → Break into smaller, more discrete steps
- If >50% need worked examples → Add complete end-to-end workflow walkthrough
- If >30% need "step-by-step" → Add more scaffolding throughout

#### **Lesson 07: Capstone Project**
**Look for:**
- Question 10: Concern about "Capstone project" (high → add more structure)
- Question 2: Overall difficulty (if "very difficult" high → capstone may need simplification)
- Question 3: Pacing (if "too fast" → allow more time or reduce scope)

**Actionable Adjustments:**
- If >40% concerned about capstone → Add more milestones and check-ins
- If >30% struggle with time → Consider reducing project scope or extending timeline
- If >50% need "peer collaboration" → Add optional collaboration components

## Quick Response Patterns to Watch For

### Pattern 1: Struggling Students (Technical Challenges)
**Signals:**
- Q1: 1-2 (very/somewhat uncomfortable with Python)
- Q6: "Python basics", "Finding files/folders" selected
- Q11: "More Python basics review" selected

**Response**: Add Python review resources, more scaffolding, simpler examples

### Pattern 2: Confident Students (Need More Challenge)
**Signals:**
- Q1: 4-5 (comfortable/very comfortable)
- Q2: "Too easy" or "Just right"
- Q3: "Too slow"
- Q14: Requests for more advanced content

**Response**: Add optional advanced sections, extend examples, provide challenge problems

### Pattern 3: Time Constraints
**Signals:**
- Q4: "More than 7 hours" or "6-7 hours" (>50% of students)
- Q3: "Too fast" (>40%)
- Q10: "Time constraints" selected

**Response**: Reduce lesson content, streamline assignments, provide time-saving shortcuts

### Pattern 4: AI Tool Struggles
**Signals:**
- Q8: "Not helpful" or "Somewhat helpful" (>30%)
- Q9: Multiple AI challenges selected
- Q10: High concern about AI Validation

**Response**: Add AI prompt templates, more AI usage examples, validation strategies

## Priority Matrix for Adjustments

### High Priority (Address Immediately):
- >60% of students report same challenge
- >50% need same support
- >40% have same concern about upcoming lessons

### Medium Priority (Address if Time Permits):
- 40-60% report issue
- Can be addressed with minor modifications
- Enhances but doesn't fix critical issues

### Low Priority (Nice to Have):
- <40% report issue
- Enhancements rather than fixes
- Can note for future course iterations

## Example Response Scenarios

### Scenario 1: Wide Skill Variation
**Data Shows:**
- Q1: Mixed (many 1s and 2s, many 4s and 5s)
- Q11: Both "Python basics review" and "Don't need support" selected

**Response:**
- Create tiered content: Core (required) + Optional advanced sections
- Add "Quick Python Review" appendix to Lesson 05
- Provide both basic and advanced examples

### Scenario 2: AI Tools Not Effective
**Data Shows:**
- Q8: Mostly "Somewhat helpful" or lower
- Q9: "Don't know how to write effective prompts" highly selected

**Response:**
- Add prompt template library to Lesson 05
- Include "Prompt Engineering Review" section
- Add examples of good vs. bad prompts

### Scenario 3: Pacing Too Fast
**Data Shows:**
- Q3: >50% "too fast" or "way too fast"
- Q4: >60% spending "6+ hours"

**Response:**
- Reduce Lesson 06 content (may already be streamlined)
- Provide pre-class preparation materials
- Extend deadlines if possible
- Add "Time-Saving Tips" sections

## Questions to Ask Yourself After Analysis

1. **What is the single biggest challenge for >50% of students?**
   - Address this first in upcoming lessons

2. **What support do >50% of students need?**
   - This is the highest-impact addition

3. **What are confident students (Q1: 4-5) saying?**
   - Ensure they're not bored - add optional advanced content

4. **What are struggling students (Q1: 1-2) saying?**
   - Ensure they're not left behind - add scaffolding

5. **Is the course achieving its learning objectives?**
   - Q5 + Q12 responses should indicate this
