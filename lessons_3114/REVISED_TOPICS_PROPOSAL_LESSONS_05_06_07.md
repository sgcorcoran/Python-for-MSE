## Proposed New Topics: Lessons 05-07

### Lesson 05: AI Validation & Critical Evaluation (Week 9)

#### Why This Topic?
Students have learned to use AI tools but haven't learned to critically evaluate outputs. This is a **critical skill gap** for scientific work.

#### Learning Objectives
By the end of this lesson, students will be able to:
- **Identify common AI errors** in materials science contexts
- **Validate AI-generated code** before using it
- **Check AI statistical recommendations** for appropriateness
- **Verify AI interpretations** against domain knowledge
- **Use AI as a tool, not a replacement** for critical thinking

#### Content Structure (3 hours total)

**1. Mini-Lecture: AI Error Types (30 min)**
- **Factual errors**: AI makes up data, properties, relationships
- **Logical errors**: AI misunderstands problem requirements
- **Code errors**: AI generates non-functional or incorrect code
- **Statistical errors**: AI recommends inappropriate tests
- **Interpretation errors**: AI misinterprets results

**2. Guided Activity: Code Validation (60 min)**
- **Task**: AI generates code for statistical analysis
- **Process**: Students must validate before running
  - Check imports and dependencies
  - Verify logic matches problem
  - Test with simple examples
  - Compare with known correct solutions
- **AI Integration**: Use AI to check AI (cross-validation)
- **Outcome**: Students catch 3-5 errors in AI-generated code

**3. Guided Activity: Statistical Validation (60 min)**
- **Task**: AI recommends statistical test
- **Process**: Students must validate recommendation
  - Check assumptions match data
  - Verify test is appropriate for question
  - Compare with alternative tests
  - Validate AI reasoning
- **AI Integration**: Ask AI to justify recommendation, then verify
- **Outcome**: Students evaluate and correct AI statistical suggestions

**4. Reflection & Synthesis (30 min)**
- **Questions**: 
  - What types of errors did you catch?
  - When is AI most likely to be wrong?
  - How do you balance trust vs. verification?
- **Deliverable**: Error detection checklist (created with AI assistance)

#### Assignment (Due Week 10)
**AI Output Validation Report** (50 points)
- Receive AI-generated analysis (code + interpretation)
- Identify and document 5+ potential errors
- Correct errors and re-run analysis
- Write brief report comparing AI vs. corrected versions
- Submit: corrected code + validation report

#### Key Features
- ✅ **Builds on Lesson 04**: Validates statistical recommendations
- ✅ **Builds on Lesson 02**: Critical evaluation of AI outputs
- ✅ **Practical focus**: Hands-on error detection
- ✅ **Realistic scope**: 3 hours achievable
- ✅ **High value**: Critical missing skill

### Lesson 06: Integrated Workflows & Research Efficiency (Week 10)

#### Why This Topic?
Students know individual tools but don't know how to combine them efficiently. This addresses **workflow integration** gap.

#### Learning Objectives
By the end of this lesson, students will be able to:
- **Combine AI tools** into efficient research workflows
- **Use AI for literature analysis** and information extraction
- **Create reproducible workflows** that document AI usage
- **Optimize time** by using right tool for right task
- **Integrate** prompts, analysis, and documentation

#### Content Structure (3 hours total)

**1. Mini-Lecture: Integrated Research Workflows (30 min)**
- **Workflow stages**: Literature → Data → Analysis → Documentation
- **Tool selection**: Which AI tool for which task?
- **Efficiency principles**: Minimize redundancy, maximize automation
- **Documentation requirements**: Track AI usage for reproducibility

**2. Guided Activity: Literature Analysis Workflow (75 min)**
- **Task**: Extract information from research papers using AI
- **Process**:
  - Upload paper to Claude/ChatGPT
  - Use AI to extract key findings, methods, data
  - Validate extracted information
  - Create structured summary
- **AI Integration**: 
  - ChatGPT for detailed extraction
  - Claude for synthesis
  - Prompt library for consistency
- **Outcome**: Students create structured literature summary from 2-3 papers

**3. Guided Activity: Complete Analysis Workflow (60 min)**
- **Task**: Complete analysis from raw data to report
- **Process**:
  - Data loading (Lesson 01 skills)
  - Statistical analysis (Lesson 04 skills)
  - AI-assisted interpretation
  - Dashboard creation (Lesson 03 skills)
  - Documentation with AI tracking
- **AI Integration**: Multiple AI tools in sequence
- **Outcome**: Students complete full workflow in 60 minutes

**4. Reflection & Synthesis (15 min)**
- **Questions**:
  - Which workflow stages took longest?
  - Where did AI help most?
  - What would you do differently?
- **Deliverable**: Personal workflow template (AI-generated)

#### Assignment (Due Week 11)
**Integrated Workflow Project** (50 points)
- Choose materials science question
- Complete full workflow: literature → data → analysis → dashboard
- Document all AI tool usage (which tool, when, why)
- Create reproducible notebook
- Submit: notebook + workflow documentation

#### Key Features
- ✅ **Builds on ALL previous lessons**: Integrates everything
- ✅ **Practical focus**: Real-world workflows
- ✅ **Efficiency focus**: Time-saving techniques
- ✅ **Realistic scope**: 3 hours achievable
- ✅ **High value**: Students learn to work efficiently

### Lesson 07: Practical Research Project (Weeks 11-12)

#### Why This Topic?
Instead of theoretical capstone requiring mastery of all concepts, create **practical project** that applies learned skills to real research question.

#### Learning Objectives
By the end of this project, students will be able to:
- **Apply AI tools** to real materials science problem
- **Integrate all learned skills** into cohesive workflow
- **Document AI usage** for reproducibility
- **Communicate findings** clearly and professionally
- **Evaluate their own work** critically

#### Project Structure (6 hours total over 2 weeks)

**Week 11: Project Planning & Analysis (3 hours)**

**Phase 1: Project Selection (30 min)**
- Choose from 3 pre-selected research questions:
  1. **Composition-Property Relationships**: Analyze relationship between alloy composition and mechanical properties
  2. **Processing Optimization**: Identify optimal processing conditions from experimental data
  3. **Material Classification**: Classify materials based on property data

**Phase 2: AI-Assisted Planning (60 min)**
- Use AI to create project plan
- Identify required analyses
- Plan workflow
- Estimate time requirements

**Phase 3: Data Collection & Initial Analysis (90 min)**
- Load and validate data (Lesson 01)
- Use AI for data assessment (Lesson 03)
- Conduct initial statistical analysis (Lesson 04)
- Validate AI recommendations (Lesson 05)
- Create initial visualizations (Lesson 03)

**Week 12: Completion & Documentation (3 hours)**

**Phase 4: Complete Analysis & Validation (90 min)**
- Complete statistical analysis
- Create dashboard or visualization
- Validate all results
- Check for errors (Lesson 05)

**Phase 5: Documentation & Report Writing (90 min)**
- Document all AI tool usage
- Write brief technical report (3-4 pages)
- Include methodology, results, validation
- Use AI for report writing, then validate/edit

#### Deliverables (100 points total)

**1. Project Notebook** (40 points)
- Well-organized Jupyter notebook
- All analysis code
- AI tool usage clearly documented
- Validation steps included
- **Format**: Like lessons 01-04 (structured cells)

**2. Brief Technical Report** (40 points)
- 3-4 pages (not 8-12!)
- Introduction, Methodology, Results, Discussion
- AI usage documented in methodology
- Validation approach explained
- **Format**: PDF, professional but brief

**3. Workflow Documentation** (20 points)
- Which AI tools used when
- How AI outputs were validated
- Workflow efficiency reflections
- **Format**: Brief (1-2 pages) or embedded in report

**NO REQUIREMENTS FOR**:
- ❌ Extensive dashboard (optional)
- ❌ Presentation (too time-consuming)
- ❌ Complex code repository (notebook is sufficient)

#### Key Features
- ✅ **Builds on ALL lessons**: Integrates everything learned
- ✅ **Practical focus**: Real research questions
- ✅ **Realistic scope**: Achievable in 2 weeks (6 hours)
- ✅ **Flexible**: Students choose project type
- ✅ **Validation emphasis**: Must validate AI outputs (Lesson 05)
- ✅ **Documentation focus**: Learn reproducibility
